# QCM Prof  A Flutter application designed to simplify the creation, management, and correction of multiple-choice exams (QCM).  ## Features - Create exams manually. - Import exams using JSON files. - Manage questions and multiple-choice answers. - Generate multiple exam versions. - Shuffle questions and answers. - Correct exams and calculate scores. - Generate PDF exam documents. - Manage exams and their versions.  ## Technologies - Flutter - Dart - SQLite - JSON - PDF generation  ## Platform Android
